# MEMORY

Durable scratchpad. Survives restarts. Loaded into atlas's context every
session.

**Write here:**

- Facts the user tells you to remember
- Setup details future-you should know (paths, tokens' rotation history,
  MCP server configs, smart-home device IDs as you add them)
- Recurring annoyances you fixed, note the fix
- Patterns / preferences that took multiple sessions to establish

**Don't write here:**

- Ephemeral conversation
- Summaries of single tasks
- Anything `git log` or the code itself already documents
- Sensitive third-party content (DMs, emails, health info about others)

Keep entries short. One concept per heading. Date them when the date
matters.
